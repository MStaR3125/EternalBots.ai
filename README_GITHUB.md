# 🕊️ EternalBots - Pope Francis AI

> An AI-powered conversational bot that embodies Pope Francis's personality, wisdom, and compassion. Features real-time voice interaction, AI-generated responses, and animated avatar.

[![Python 3.13](https://img.shields.io/badge/python-3.13-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Gradio](https://img.shields.io/badge/Built%20with-Gradio-orange)](https://gradio.app/)

## 🌟 Features

- 🎤 **Real-time Speech Recognition** - Powered by OpenAI Whisper
- 🤖 **AI Chatbot** - TinyLlama 1.1B with Pope Francis personality
- 🎬 **Animated Avatar** - Dynamic talking animations
- 🌐 **Web Interface** - Easy-to-use Gradio UI
- 🔒 **100% Local** - All processing happens on your machine
- 🎯 **Zero Cloud Dependencies** - Complete privacy

## 🚀 Quick Start

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/MStaR3125/eternalbots-pope-francis.git
cd eternalbots-pope-francis
```

2. **Create virtual environment**
```bash
python -m venv .venv
.\.venv\Scripts\Activate.ps1  # Windows
```

3. **Install dependencies**
```bash
pip install -r requirements-py313.txt
```

4. **Run the application**
```bash
# Windows - Double-click START_SERVER.bat
# Or: python app/server.py
```

5. **Open browser to http://127.0.0.1:7861**

## 🎯 Usage

1. Allow microphone access
2. Speak your question
3. Click "Process Audio"
4. Receive Pope Francis AI response with animated avatar!

## 📚 Tech Stack

- OpenAI Whisper (Speech Recognition)
- TinyLlama 1.1B (Language Model)
- OpenCV (Avatar Animation)
- Gradio (Web Interface)
- PyTorch (Deep Learning)
