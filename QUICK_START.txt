# 🚀 Quick Start - EternalBots Pope Francis

## Run the Application

```powershell
.\start.ps1
```

Then open: **http://127.0.0.1:7861**

---

## First Run? (One-Time Setup)

⏳ **Takes 10-15 minutes** - Downloads AI models (~2GB)
📡 **Internet required** - Models from Hugging Face
☕ **Be patient** - Subsequent runs are fast!

---

## Using the App

1. 🌐 Open browser → http://127.0.0.1:7861
2. 🎤 Allow microphone access
3. 🗣️ Speak your question
4. 🖱️ Click "Process Audio"
5. ⏳ Wait for Pope Francis' response
6. 🎬 Watch animated avatar + listen to response

---

## Working Features ✅

- Speech Recognition (Whisper)
- AI Responses (TinyLlama as Pope Francis)
- Animated Avatar (OpenCV)
- Web Interface (Gradio)

## Limited Features ⚠️

- Voice Cloning (TTS disabled - Python 3.13 limitation)
- Silent audio used as fallback

---

## Troubleshooting

### Server won't start?
```powershell
# Test imports
.\.venv\Scripts\python.exe -c "import torch, whisper, gradio; print('OK')"
```

### Microphone not working?
- Check browser permissions
- Allow microphone in Windows Settings

### Still stuck?
- Read: `HOW_TO_RUN.md`
- Check terminal output for errors

---

## Stop the Server

Press `Ctrl+C` in terminal
