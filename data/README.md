# Data Directory

This directory should contain:

1. **pope_ref.wav** - A 6-10 second audio sample of Pope Francis's voice
   - Used for voice cloning (if TTS is available)
   - Format: WAV, 16-bit, mono preferred

2. **pope_face.jpg** - A square portrait photo of Pope Francis  
   - Recommended size: 512x512 pixels
   - Used for avatar animation
   - Format: JPG or PNG

## Where to Get These Files

### Voice Sample (pope_ref.wav)
- Search YouTube for Pope Francis speeches
- Extract a clean 6-10 second clip
- Convert to WAV format using tools like Audacity or FFmpeg

### Portrait (pope_face.jpg)
- Find a high-quality, front-facing portrait
- Crop to square (512x512 recommended)
- Save as pope_face.jpg

## Note

These files are not included in the repository for copyright reasons. Users must provide their own reference files.
